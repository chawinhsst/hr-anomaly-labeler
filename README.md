# 🧠 Anomaly Labeling Tool

This is a Streamlit-based app for interactively labeling anomalies in heart rate data.

## Features

- Upload CSV files with `Time`, `HeartRate`, and optional metrics
- Click on chart points to toggle anomaly labels
- View and remove labeled anomalies
- Download labeled dataset
- Simple login system

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
